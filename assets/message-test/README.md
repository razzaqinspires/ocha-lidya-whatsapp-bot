# Ocha Message Test Assets

All files in this directory are synthetic local fixtures used by the owner-only `.test` message lab. Tests do not require external URLs or manually supplied media arguments.

- `sample-image.png`: image and view-once test
- `carousel-01.png`, `carousel-02.png`: carousel card headers
- `sample-sticker.webp`: sticker fixture
- `sample-audio.wav`: short generated tone, not a song
- `sample-document.pdf`: sample document
- `sample-video.mp4`: generated short MP4 fixture (when FFmpeg is available at development time)

Do not replace these fixtures with private user media.
