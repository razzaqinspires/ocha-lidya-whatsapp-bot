## Command and script registry

- Preserved: `npm run git:setup`, `npm run git:watch` (legacy Ocha-only CLI scripts).
- Added: `npm run ac:git:setup`, `npm run ac:git:watch`, `npm run git:status`, `npm run git:push`, `npm run git:push:ocha`, `npm run git:push:ac`.
- Hidden owner control: `.autopush` with aliases `.gitpush` and `.autogit`; metadata `ownerOnly: true`, `privateOnly: true`, `menu: false`.
- Targets are fixed in source: `razzaqinspires/ocha-lidya-whatsapp-bot:main` and `razzaqinspires/artificial-consciousness-component:main`. No arbitrary repository target is accepted by the command.

## Security and publication boundary

The Ocha root `.gitignore` excludes all `.private/`. The Ocha watcher never traverses that directory and additionally checks `git ls-files -- .private` before any commit. The AC watcher has a separate Git top-level root and cannot add paths to the Ocha index. Both lanes use separate least-privilege credentials, temporary askpass scripts, fixed remotes/branches, ancestry checks, path-scoped staging and no force-push. The Ocha operator archive includes selected `.private` source for deployment convenience and must never be uploaded to a public repository.
