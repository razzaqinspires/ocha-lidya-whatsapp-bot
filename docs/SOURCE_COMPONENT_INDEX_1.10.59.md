## Boundary contract

`src/plugins/owner/message-lab.js` was an unintended public-tree duplicate of the private message-test plugin. It matched the private package runtime/original bytes (49,838 bytes, SHA-256 `c47883b8cf6d6c3de18085d4e43a82c543768edd0df6782f52a97770fdd068c6`) and was removed only from the public `src/plugins` location. Both private copies remain unmodified. The public `src/plugins/owner/message-test-catalog.js` is a host bridge dependency and remains included.

The shared policy is applied independently at three boundaries: runtime plugin loader, ACIE static command scan, and release archive filter. This prevents a private module path from entering a public plugin registry or release file list by mistake. `.test` remains registered by private runtime only after manifest integrity, owner-only/private-only flags, and command/alias collision gates pass.
