## Menu configuration contract

`config.menu` contains `showDescriptions`, `template`, `font`, `order`, `spacing`, `topBorder`, `bottomBorder`, and `pagination.{enabled,pageSize}`. The shipped defaults are `corporate`, `normal`, `category`, spacing `0`, both borders enabled, descriptions disabled, and text fallback pagination disabled with a page size of 50.

The supported theme keys are `corporate`, `minimal`, `terminal`, `elegant`, `aurora`, `classic`, `compact`, `minimalist`, `cyberpunk`, `fantasy`, `ocean`, `sunset`, `emerald`, `sakura`, `monochrome`, and `royal`. Font keys are `normal`, `bolditalic`, `bold`, `sans`, `mono`, `superscript`, `double`, `smallcaps`, `fraktur`, `italic`, `script`, and `circled`. Sorting supports `category`, `az`, and `za`; spacing supports integers `0`–`3`; text page size supports integers `10`–`200`.

`.setmenu` keeps `ownerOnly: true` and `privateOnly: true` and verifies the configured owner against message sender metadata before writing. `.menu` continues to derive its command list from the live plugin registry; it does not maintain a parallel command registry. Native-flow command pages show at most seven command rows plus navigation rows to stay within the existing WhatsApp list contract. `pages` and `limit` govern the text fallback renderer; native-flow category navigation remains paginated when needed.

## Compatibility and non-goals

The Whiskay menu/settings implementation was read as a design reference only. No Whiskay dependencies, data files, business logic, menu widgets, profile/economy/energy integrations, custom image upload, or quoted-message experiments were copied. The Ocha menu banner remains `assets/menu-banner.jpg`. The private Ocha runtime and independent AC component were not modified by this menu release.
